# ggen-legacy v26.9.28

v26.9.28 changes the unit of reconstitution from a repository-local replacement
program into a **composed software-manufacturing court**.

The repository does not absorb the implementation of today's ecosystem. It
binds exact capability owners, reconstructs a bounded legacy contract, delegates
manufacture to ggen/ggen-marketplace/ggen_igniter, and independently verifies
the resulting subject.

## Production equation

```text
legacy repository
→ observable contract O
→ admitted contract O*
→ HDDL/FOND plan
→ ggen marketplace composition
→ deterministic manufacture μ(O*)
→ GraphLaw/read-plane courts
→ SA2A consequence construction
→ XaaS BRCE for consequential DO
→ receipt
→ replay
→ Release Admission
→ separately authorized Sunset Admission
```

The critical v26.9.28 change is **reuse ownership**. GraphLaw owns semantic law,
AshR2RML owns the VKG/read plane, AshA2A owns the consequence protocol, XaaS
owns consequential actuation, Affidavit owns cryptographic trust, and the
planning/runtime repositories retain their existing domains.

No engine is vendored merely to make ggen-legacy look complete.

## Standing

The v26.9.28 composition source starts at `PARTIAL_ALIVE`. It can reach
`ALIVE / REFERENCE_CONFORMANT` only when the exact-head crown verifies the
local contract, probes required external exact SHAs, obtains two byte-identical
non-promoting manufacture receipts, rejects negative controls, and binds the
result to the exact ggen-legacy revision.

That crown does not prove an external customer deployment or grant Sunset
Admission to a real predecessor.
