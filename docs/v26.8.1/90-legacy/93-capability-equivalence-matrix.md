## Reproduction

```bash
python3 - <<'EOF'
import rdflib
from collections import Counter, defaultdict
g = rdflib.Graph()
g.parse("ontology/v26.8.1/legacy-capabilities.ttl", format="turtle")
NS = rdflib.Namespace("https://ggen.chatmangpt.com/ontology/v26.8.1#")
rows = defaultdict(Counter)
for s in g.subjects(rdflib.RDF.type, NS.LegacyCapability):
    sub = str(g.value(s, NS.owningSubsystem))
    disp = str(g.value(s, NS.hasDisposition)).split('#')[-1]
    rows[sub][disp] += 1
print(dict(rows))
EOF
```
