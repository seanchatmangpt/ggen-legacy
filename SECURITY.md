# Security Policy

Project 001 currently contains documentation and bootstrap authority. Product implementation security support begins after source admission.

Report suspected vulnerabilities through GitHub Security Advisories. Do not publish exploit details, credentials, customer source, personal data, or infrastructure secrets in a public issue.

A report should identify the exact coordinate, trust boundary, prerequisites, observable consequence, reproduction, and containment. Triage states are `ACKNOWLEDGED`, `REPRODUCED`, `NOT_REPRODUCED`, `DUPLICATE`, `OUT_OF_SCOPE`, and `REMEDIATED`.

This policy does not claim certification, regulatory compliance, a response-time warranty, or production support availability. Those require contract and evidence.
