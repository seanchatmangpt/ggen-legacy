Manufacture deterministic repository diagnostics, repair plans, validation sessions, receipts, and independent promotion evidence.

## One-command UX

```bash
python3 tools/ecosystem-doctor.py doctor
python3 tools/ecosystem-doctor.py status
python3 tools/ecosystem-doctor.py resume
python3 tools/ecosystem-doctor.py explain seanchatmangpt/ggen
python3 tools/ecosystem-doctor.py plan --mode full --json
python3 tools/ecosystem-doctor.py run --repo seanchatmangpt/ggen --mode fast --execute
python3 tools/ecosystem-doctor.py verify
```

The doctor is diagnostic and operational. It cannot grant aggregate `ALIVE`; promotion belongs exclusively to `verifiers/verify_ecosystem_alive.py`.

## QoL guarantees

- Human table output and stable JSON output use the same computed model.
- `resume` selects the first dependency-ordered blocker and emits a copy-paste command.
- `explain` reports the repository role, exact source identity, commands, receipts, and next repair.
- `run` is inert unless `--execute` is supplied.
- Validation sessions are resumable through receipt files beneath `target/ecosystem-alive`.
- Unknown tools, missing workspaces, command failures, and incomplete receipts remain distinct.
- Source reconstruction is not repository validation.
- A generated doctor cannot independently certify its own generated implementation.
