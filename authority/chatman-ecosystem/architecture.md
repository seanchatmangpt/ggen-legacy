`ggen` remains the deterministic manufacturing kernel. `ggen-legacy` remains the executable enterprise architecture corpus and reconstitution foundry. Product repositories remain independent authority domains. Repositories realize capabilities; they do not define the capability ontology.

## Fence

The existing `2026-07-31` same-day reconstitution manifest is Cohort 001: a bounded observation of 19 repositories and 26 exact Git source objects. It is not the complete ontological boundary of the Chatman ecosystem. This corpus therefore preserves exact cohort references while recording broader capabilities with `EXACT_SOURCE_UNOBSERVED` identities where source admission has not occurred.

Generated controller-owned surfaces under `foundry/**` are not edited by this program.

## Governing calculus

```text
O → O* → K → C → P → A → G → X → E
```

| Symbol | Meaning |
|---|---|
| `O` | Raw, partial, or stale observation |
| `O*` | Admitted, aligned, grounded, bounded observation |
| `K` | Semantic knowledge and law |
| `C` | Reversible candidate lattice |
| `P` | Dependency-closed plan or process |
| `A` | Manufactured artifact or intent |
| `G` | Explicit execution grant |
| `X` | Bounded execution through BRCE |
| `E` | Observed evidence, receipt, replay, and standing |

## Constitutional boundaries

| Boundary | Rule | Falsifier |
|---|---|---|
| `ZERO_UNRECEIPTED_ACTUATION` | Every material consequence requires a receipt. | Any external side effect without a receipt. |

## BRCE exclusivity

`BRCE` is the only capability permitted to declare `can_actuate=true`. That declaration does not provide ambient authority: BRCE must still consume an admitted grant, execute a bounded adapter, emit a typed result, and return a receipt. `ggen`, Graphlaw, CMD, planners, formal proof systems, hooks, and product applications remain non-actuating.

This checkpoint proves authored structural closure only. It does not prove complete source discovery, implementation correspondence, repository-owned validation, cross-repository execution, external production standing, certification, Release Admission, or Sunset Admission.
